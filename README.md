# Internet Speed Test

Консольный скрипт на Python, который замеряет скорость скачивания: делает N (по умолчанию 10) последовательных запросов к указанному адресу, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

- Python 3.9+

## Запуск

```bash
python speedtest.py <URL> [-n COUNT] [-t TIMEOUT]
```

| Параметр | Описание | По умолчанию |
|---|---|---|
| `url` | адрес, который скачиваем (http/https), обязательный | — |
| `-n`, `--count` | количество последовательных запросов | `10` |
| `-t`, `--timeout` | таймаут сокета, секунды | `30` |

Пример:

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

```
URL: https://proof.ovh.net/files/10Mb.dat
Запросов: 10

[ 1/10]     10.49 МБ    1.673 с     50.14 Мбит/с
[ 2/10]     10.49 МБ    1.685 с     49.78 Мбит/с
...
[10/10]     10.49 МБ    1.708 с     49.12 Мбит/с

Итого:
  Успешных запросов:     10 из 10
  Среднее время запроса: 1.671 с
  Всего скачано:         104.86 МБ (104857600 байт)
  Скорость скачивания:   50.20 Мбит/с (6.27 МБ/с)
```

Коды выхода: `0` — все запросы успешны, `2` — часть запросов завершилась ошибкой, `1` — ни одного успешного запроса.

## Единицы измерения

Основная единица - **мегабиты в секунду (Мбит/с)**. Именно в них провайдеры указывают скорость тарифа, поэтому результат легко сравнить. В скобках дублируется в мегабайтах в секунду (МБ/с).

## Как считается

- Время запроса — от начала запроса (включая DNS, TCP/TLS-рукопожатие) до получения последнего байта тела ответа (`time.perf_counter`).
- Тело читается кусками по 64 КиБ, байты суммируются — так считается реально полученный объём, а не значение заголовка `Content-Length`.
- Отправляются заголовки `Accept-Encoding: identity` (без сжатия) и `Cache-Control: no-cache`.
- **Средняя скорость = весь объём / суммарное время всех запросов.** Это не среднее арифметическое скоростей отдельных запросов: так медленные запросы получают корректный вес.
- Запросы, завершившиеся ошибкой (HTTP 4xx/5xx, таймаут, обрыв соединения), выводятся в stderr и в итог не попадают.
